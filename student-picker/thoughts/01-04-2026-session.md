## Key Decisions
1. **termimg API simplification**: v0.0.7 removed `terminal.New()` and `drawers.Drawers` - now uses simple `termimg.DrawFile(path, bounds)` and blank import `drawers/all` to register drawers
2. **Grid icon rendering approach**: Icons rendered via Kitty protocol commands after View() returns, using `tea.Cmd` batch pattern. Grid cells reserve empty lines where icons overlay.
3. **Icon position calculation**: `gridX = 2 + col*thumbW`, `gridY = 3 + row*thumbH`, accounting for borders and tabs

## Technical Context

### termimg v0.0.7 API
```go
import "github.com/srlehn/termimg"
import _ "github.com/srlehn/termimg/drawers/all"

// Simple draw call
termimg.DrawFile(imagePath, image.Rect(x, y, x+w, y+h))

// Clear all images
termimg.CleanUp()
```

### Grid Layout Constants
```go
const (
    thumbW   = 18  // thumbnail width in cells
    thumbH   = 10  // thumbnail height in cells

    PreviewH = 20

```

### Icon Position Calculation
```go
gridX := 2 + col*thumbW   // 2 = left border + padding
gridY := 3 + row*thumbH   // 3 = header lines (border + tabs)
```
