## Key Decisions
1. **termimg API simplification**: v0.0.7 removed `terminal.New()` and `drawers.Drawers` - now uses simple `termimg.DrawFile(path, bounds)` and blank import `drawers/all` to register drawers
2. **Grid icon rendering approach**: Icons rendered via Kitty protocol commands after View() returns, using `tea.Cmd` batch pattern. Grid cells reserve empty lines where icons overlay.
3. **Icon position calculation**: `gridX = 2 + col*thumbW`, `gridY = 3 + row*thumbH`, accounting for borders and tabs
