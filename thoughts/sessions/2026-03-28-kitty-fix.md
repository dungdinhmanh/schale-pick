# Session Log: student-picker Kitty Graphics Fix

**Date**: 2026-03-28  
**Session ID**: `ses_current`

## Problem
Images in student-picker were not displaying in preview panel.

## Root Causes Found

### 1. Original Issue: `a=d` delete after
```go
// OLD CODE - images deleted when text written
fmt.Printf("\033_Ga=t:f,file=%s,x=%d,y=%d,w=%d,h=%d,a=d\033\\", ...)
// a=d means "delete after" - image deleted when text renders
```

### 2. Position Issue - Image at wrong location!
The image was being sent at `x=1,y=1` (top-left of terminal) but the preview panel is on the RIGHT side of the screen at approximately column 68-107.

### 3. Timing Issue
Image was being sent BEFORE the view renders, so text would overwrite it.

## Solution Applied

### Changed to Composition Mode
```go
// main.go line 79-88 - NEW CODE  
func renderKittyImage(path string, col, row, w, h int) {
    seq := fmt.Sprintf("\033_Ga=t:f,file=%s,x=%d,y=%d,w=%d,h=%d,C=1,U=1,f=32\033\\",
        path, col-1, row-1, w, h)
    os.Stderr.WriteString(seq)  // Bypass Bubbletea buffering
}

func renderImagePreview(path string, w, h int) {
    if strings.Contains(os.Getenv("TERM"), "kitty") {
        renderKittyImage(path, 30, 1, w, h)  // Position 30,1 (right side)
        return
    }
    // chafa fallback...
}
```

## Key Parameters
| Param | Value | Meaning |
|-------|-------|---------|
| `a=t` | Action=Transmit | Display the image |
| `f=file` | Format=File path | Read from file directly |
| `C=1` | **Composition ON** | Image composites under text |
| `U=1` | Unicode placeholder | Transparent placeholder chars |
| `f=32` | Format=RGBA 32bit | Color format |
